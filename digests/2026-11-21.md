### [Welcome Inkling 2 Mini, Cutting-edge Performance for your Local Setup](https://huggingface.co/blog/inkling2mini)
_Hugging Face · 2026-11-20_

Thinking Machines Lab released Inkling 2 Mini, a looped multimodal Mixture-of-Experts model featuring 26B total parameters and a 1M-token context window designed for efficient local execution. For developer tools and AI agents, this efficient local architecture makes advanced code reasoning, tool use, and document analysis feasible on consumer hardware without relying on cloud-based APIs.

---

### [Introducing harness adapters: adapt your favorite model to your harness to improve performance and cost](https://huggingface.co/blog/harness-adapters-at-scale)
_Hugging Face · 2026-11-20_

Hugging Face released harness adapters that use reinforcement learning to optimize open-weights models for specific agent harnesses and task distributions. This technique allows developers to significantly boost task success rates while reducing token usage and reasoning overhead during agentic execution.
