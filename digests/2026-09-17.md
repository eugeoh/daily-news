## Frontier Model & Research

### [Introducing the Life Sciences Verification Program](https://www.anthropic.com/news/life-sciences-verification-program)
_Anthropic · 2026-09-17_

Anthropic launched a verification program that gives verified life sciences organizations access to AI models with fewer restrictions on biology-related tasks. This allows researchers to perform complex biological work without constantly being blocked by safety filters, while still maintaining security monitoring behind the scenes.


## Software Engineering

### [Migrating the GitHub Copilot runtime to Rust, using Copilot](https://github.blog/ai-and-ml/generative-ai/migrating-the-github-copilot-runtime-to-rust-using-copilot/)
_GitHub Blog · 2026-09-17_

GitHub used AI coding agents to completely rewrite 800,000 lines of their Copilot system into a different programming language called Rust. This proves that AI can now handle massive, complex software engineering tasks that were previously too expensive and time-consuming for human teams alone.
