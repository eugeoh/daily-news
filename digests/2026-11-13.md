### [Introducing WebMCP support: your docs’ MCP server, now in the browser](https://www.gitbook.com/blog/web-mcp)
_GitBook · 2026-11-11_

GitBook has integrated support for WebMCP, a proposed browser standard that allows published documentation sites to automatically expose their existing Model Context Protocol servers to browser-based AI agents. This allows AI agents operating inside a browser to fetch structured data and search documentation directly instead of scraping rendered pages, fundamentally shifting how technical knowledge is programmatically consumed at the edge.

### [LLMON: An LLM-Native Markup Language, now in Granite 4.1 3B and 8B](https://huggingface.co/blog/ibm-granite/llmon-an-llm-native-markup-language-now-in-granite)
